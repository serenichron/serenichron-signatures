How to install your signature

Click Copy signature above, then follow the steps for your email client. The copy includes formatting, logo, and links.

Apple Mail paste works

  1. Mail → Settings → Signatures.
  2. Pick your account, click + to add a signature.
  3. Uncheck "Always match my default message font".
  4. Select the placeholder text and Paste (⌘V).

Outlook (Mac & new Windows)

  1. Outlook → Settings → Signatures (or Mail → Compose & reply).
  2. Create a new signature, click into the edit box.
  3. Paste (⌘V / Ctrl+V). Set it as default for new mail & replies.

Outlook (classic Windows)

  1. Download HTML instead of copy.
  2. Open the file in a browser, select all (Ctrl+A), copy (Ctrl+C).
  3. File → Options → Mail → Signatures, paste into a new signature.

Gmail

  1. Gmail → Settings (gear) → See all settings.
  2. Scroll to Signature → Create new.
  3. Paste into the box and Save changes at the bottom.
